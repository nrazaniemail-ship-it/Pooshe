# پوشه | Pooshe

دستیار محلی مدیریت پرونده‌های حقوقی و کیفری.

نسخه وب/PWA فارسی و راست‌چین با ذخیره‌سازی محلی، میزکار مرحله‌ای، آرشیو، تقویم، کتابخانه و تنظیمات.

## اجرا

- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`

## حریم خصوصی

اطلاعات در مرورگر/دستگاه کاربر ذخیره می‌شود. در این نسخه ورود و همگام‌سازی ابری فعال نیست. از بخش تنظیمات به‌طور منظم نسخه پشتیبان JSON تهیه کنید.

## اعلان‌ها

اعلان‌های وب هنگام فعال بودن برنامه قابل نمایش‌اند. برای زمان‌بندی بومی و قابل اتکاتر در Android، نسخه Capacitor از Local Notifications استفاده می‌کند.

## یادآوری حقوقی

الگوهای مراحل صرفاً چک‌لیست مدیریتی هستند و جایگزین بررسی قوانین جاری، مهلت‌های قانونی و تشخیص حرفه‌ای وکیل نیستند.
