# پوشه | Pooshe

دستیار محلی مدیریت پرونده‌های حقوقی و کیفری؛ رابط فارسی و راست‌چین با الگوی میزکار مینیمال، کارت‌های پرونده و ناوبری پنج‌بخشی.

## امکانات نسخه ۱

- میزکار و ایجاد پرونده در دو مسیر حقوقی و کیفری، با دسته‌بندی تخصصی و پوشه مستقل.
- گردش کار گام‌به‌گام با وضعیت رنگی: سبز پاستیلی برای تکمیل، زرد کم‌رنگ برای گام جاری.
- الگوهای اولیه متناسب با موضوعاتی مانند چک، سفته، خانواده، ملک، سرقت و جرایم رایانه‌ای؛ قابل ویرایش برای هر پرونده.
- آرشیو با جستجو و فیلتر پرونده‌های جاری/مختومه.
- تقویم رویدادهای شروع و موعد پایان گام‌ها.
- اعلان وب و اعلان محلی Android با انتخاب ساعت و فاصله یادآوری.
- کتابخانه شخصی برای ثبت قوانین، رویه قضایی، فرم‌ها، نمونه متون و چک‌لیست‌ها.
- پوسته روشن/تیره/سیستمی، رنگ تأکیدی، تراکم نمایش، پشتیبان‌گیری و بازیابی JSON.
- ذخیره‌سازی محلی و قابلیت نصب PWA؛ بدون حساب کاربری یا همگام‌سازی ابری.

## اجرا در توسعه

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
```

ساخت خروجی وب:

```bash
npm test
npm run build
npm run preview
```

## ساخت APK اندروید

```bash
npm install
npm run android:add
npm run android:sync
cd android
./gradlew assembleDebug
```

یا از GitHub Actions، گردش کار **Build Android APK** را اجرا کنید. فایل APK در Artifact با نام `pooshe-android-debug` قرار می‌گیرد.

## انتشار وب

گردش کار GitHub Pages پس از فعال‌سازی Pages در تنظیمات مخزن و انتخاب GitHub Actions به‌عنوان Build and deployment، خروجی `dist` را منتشر می‌کند. اگر Pages در مخزن فعال نباشد، مرحله deploy با خطای 404 روبه‌رو می‌شود؛ مرحله build و آزمون‌ها مستقل از آن اجرا می‌شوند.

## حریم خصوصی و محدودیت‌های نسخه

اطلاعات در مرورگر/دستگاه کاربر (IndexedDB و localStorage) ذخیره می‌شود. ورود چندکاربره، رمزنگاری داده‌ها، همگام‌سازی ابری، بارگذاری و نگهداری امن اسناد پرونده و ثبت سوابق تغییرات در این نسخه پیاده‌سازی نشده‌اند. اطلاعات پرونده‌های واقعی و محرمانه را تا زمان افزودن لایه امنیتی و ارزیابی تخصصی، فقط در دستگاه امن و با پشتیبان‌گیری کنترل‌شده نگهداری کنید.

## یادآوری حقوقی

گردش‌کارها نمونه‌های مدیریتی‌اند، نه نظر حقوقی یا محاسبه‌گر قطعی مهلت‌های قانونی. نوع دعوا، صلاحیت مرجع، مواعد و مقررات لازم‌الاجرا باید برای هر پرونده توسط وکیل بررسی و در گام‌ها اصلاح شوند.
